## 🛠️ Technology Stack

- **Frontend:** Next.js, TypeScript, Tailwind CSS
- **Backend:** FastAPI, Python, SQLAlchemy
- **Database:** PostgreSQL
- **Migrations:** Alembic
- **Infrastructure:** Docker Compose
- **Product Images:** Local image assets sourced from Unsplash
